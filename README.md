# 鸿蒙打卡 · 番茄专注与习惯养成

一个零依赖、单文件运行的 Web 作品：把「番茄专注」和「每日习惯打卡」合在一起，界面参考 HarmonyOS 的深色设计语言。

## 为什么做这个作品

日常学习华为云 / 鸿蒙开发资料时，最容易断的是专注节奏和打卡习惯。市面上的番茄钟大多要注册账号、装 App，
这个作品刻意做成**打开网页就能用、数据只存本地**的形态，作为每天的学习陪伴工具。

## 核心功能

- **番茄计时**：25 分钟专注 + 5 分钟休息自动切换，环形进度条实时反馈
- **进度可视**：SVG 圆环按剩余时间收缩，专注蓝 / 休息绿两套配色
- **当日统计**：今日番茄数、累计专注分钟、连续使用天数
- **习惯打卡**：内置 4 个学习习惯（早起 / 阅读 / 运动 / 复盘），勾选即保存
- **本地持久化**：使用 localStorage 按日期分桶存储，无需后端、不上传任何数据
- **快捷操作**：空格开始/暂停，R 重置；专注结束时可选桌面通知

## 运行方式

```bash
# 方式一：直接双击 index.html
# 方式二：起一个静态服务
python -m http.server 8080
# 浏览器打开 http://localhost:8080
```

无需安装依赖、无需构建步骤，兼容 Chrome / Edge / Safari 等主流浏览器。

## 技术实现

| 项 | 说明 |
|---|---|
| 结构 | 单文件 HTML，无框架、无外部 CDN |
| 样式 | 原生 CSS 变量 + Grid/Flex 布局，深色主题 |
| 进度环 | SVG `<circle>` + `stroke-dasharray` 计算偏移量 |
| 状态 | 原生 JS 闭包管理计时器，`setInterval` 每秒 tick |
| 存储 | `localStorage`，key 按 `pomo_YYYY-MM-DD` 分桶 |
| 通知 | Notification API，首次点击时申请权限 |

## 交互说明

1. 点击「开始专注」，倒计时开始，圆环随时间收缩
2. 25 分钟结束自动记为 1 个番茄，并切到 5 分钟休息
3. 下方习惯列表勾选后立即写入本地存储，刷新不丢
4. 点「重置」回到 25:00 待机状态
